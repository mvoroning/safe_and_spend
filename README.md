# Т-Бюджет

Смотрит, укладываешься ли ты в свой обычный темп трат до следующей зарплаты.

**Открыть:** https://<твой-логин>.github.io/safe_and_spend/

## Как пользоваться

1. Приложение Т-Банка → Дебетовая карта → Выписка и справки →
   **Справка о движении средств**. Период — хотя бы полгода.
2. Открой страницу и выбери скачанный PDF.
3. Ответь на пару вопросов о своих счетах и посмотри результат.

## Куда уходят данные

Никуда. Справка читается в браузере: сервера у страницы нет, отправлять
данные некуда. Из внешнего подгружаются только сам движок (Pyodide) и
библиотека чтения PDF — с публичных CDN, без содержимого справки.

Ответы на вопросы о счетах остаются в памяти браузера (`localStorage`),
чтобы не отвечать заново при следующей загрузке. Кнопка «Скопировать ответы»
отдаёт безразмерную выжимку — доли бюджета и длины циклов, без рублей,
без описаний операций и без зарплаты. Отправлять её или нет, решаешь ты.

## Модель ещё сырая

Она собрана на данных одного человека. Если увидишь ерунду — так и скажи:
это и есть цель показа. Особенно интересны случаи, где модель не угадала
границу зарплатного цикла или посчитала накоплениями то, что ты просто
переложил на другой счёт.
